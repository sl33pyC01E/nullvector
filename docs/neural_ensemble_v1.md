# Factorized neural teacher ensemble

The first complete neural foundation is a scheduled ensemble, not the final
monolith. It separates fast cellular rendering and control from slower ecology,
colony, society, and world-planning updates. Every selected component is bound
to its evidence report and immutable model artifact.

The failed cellular action V7 lineage is explicitly excluded. It learned useful
changed-region edits but did not beat persistence on an unseen world. The
teacher instead composes the promoted specialists. This is the system that will
generate trajectories for the later recurrent action-DiT + continuous VAE
student.

Deterministic code still schedules networks and projects unsafe outputs back
onto physical/anatomical constraints. That scaffold remains until a student
matches both quality and safety gates.
