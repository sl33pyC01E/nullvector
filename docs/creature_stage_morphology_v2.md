# Creature-stage morphology v2

This is an additive human-review authority. It does not modify the frozen developmental/controller lineage.

The bank contains six variants for each of five families. Humanoids and plants preserve the accepted prior. Animals use a squat bilateral chassis with two explicit leg pairs; the optional tail is a centered dorsal grasper, never a fifth leg. Anomalies use circular cores, mirrored orbitals, and fibrous tendril pairs. Machines use superellipse/rectilinear chassis components with wheel, track, walker, and hardpoint modules.

Every specimen contains a cell field, named organs, a load-bearing graph, and antagonistic muscles. Paired appendages must be exact mirrors. Center appendages must remain on the midline. The raster validator currently requires at least 90% reflection agreement; the review bank scores 97.5–100%.

The motion proof executes the same grounded PBD scaffold for all families. Locomotion belongs to appendage kind: legs step, roots drag, wheels roll, and native anomalies float. There is no whole-sprite rotation or directional mirroring.

This bank remains `human_review_required`. It should replace the old morphology authority only after the body plans are approved.
