# Living-body causal NCA bridge

This bridge converts any reviewed developmental organism into the native
48×48 cellular-NCA contract. It preserves exact cell identity, tissues,
organs, appendages, eight-direction bonds, health, fluids, scars, wounds,
energy, and recurrent internal state. Model outputs are projected back onto
the same cells; they cannot create chassis cells.

The runtime loads only a causal-NCA output whose metadata validation is ready.
It supports batched inference and keyed recurrent state, so detailed entities
can be updated together while distant cohorts remain at a cheaper simulation
level. External cuts and impacts are synchronized before the next learned
step. A bounded blend is retained during ensemble integration to prevent one
bad recurrent step from causing a spawn-time cascade.

The deterministic body remains the topology, severing, and conservation
validator. Promotion to game authority additionally requires all reviewed
chassis to survive healthy rollouts and to respond correctly to targeted
heart, respiratory, digestive, and neural damage.

Run the fail-closed promotion audit with:

```text
python -m forge.living_body_nca_v1 audit outputs/living_body_nca_v1/promotion_audit.json --device cuda
```

The audit evaluates the ten reviewed base/grafted chassis twice, checks exact
replay, rejects spawn collapse, and compares matched organ ablations with each
healthy counterpart. An experimental result is preserved but is not eligible
for game integration.
